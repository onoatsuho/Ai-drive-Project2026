# My Express Site

Express + TypeScript + EJSを使用して作成したWebサイトです。

## 使用技術

- Node.js
- Express
- TypeScript
- EJS
- HTML / CSS / JavaScript
- Vercel

## ローカルでの実行

パッケージをインストールします。

```bash
npm install
```

開発サーバーを起動します。

```bash
npm run dev
```

ブラウザから以下へアクセスします。

```
http://localhost:3000/
```

ビルドして実行する場合は次のとおりです。

```bash
npm run build
npm start
```
